# IPLive
![Example](https://github.com/Berkxp/IPLive/blob/main/img/icon.png)
A almost Real Time IP Tracer, this tool will allow you to see ip details with a custom timeout

## How to use (After Installing)
First you have to execute with 
```bash
python lookup.py
```
- after you have to put the IP that you will lookup
- After put the IP you put a timeout (like: 1 or 0.5)
- To stop the tool is just press 'q' in your keyboard

## Installation
Linux:
```bash
sudo apt install git
sudo apt install python
pip install -r requirements.txt

```
Windows:
```
winget install Git.Git
winget install Python.Python
pip install -r requirements.txt
```
Termux:
```bash
apt update
apt upgrade -y
apt install git -y
apt install python -y
git clone https://github.com/Berkxp/IPLive.git
cd IPLive
pip install -r requirements.txt
```
